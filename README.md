# Discord OAuth2 API for JDA

## Disclaimer
This project is heavily inspired by "Oauth2 Package" from JDA-Utilities.  
Source code available [here](https://github.com/JDA-Applications/JDA-Utilities/tree/master/oauth2) or latest variant (JDA-Chewtils) [here](https://github.com/Chew/JDA-Chewtils/tree/master/oauth2).

## Changes from original
- Updated to support latest JDA and Discord API version
- Full rewrite in Kotlin
- Additional API calls
- Various fixes

### Building from source
```bash
./gradlew shadowJar
```
Add resulting libraries (build and source) to your project.

### Additional information
Project build for use with Java 21.
